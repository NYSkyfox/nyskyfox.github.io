项目说明

这是一个使用 VitePress 构建的静态网站，主色调为 #16c07c，默认使用暗色模式。

// 主色调配置
primary-color: #16c07c
// 暗色模式默认启用
dark-mode: true
🚀 部署说明：
  1. 将整个 docs 目录推送到 GitHub 仓库
  2. 在仓库设置中启用 GitHub Pages
  3. 选择 GitHub Actions 作为源
  4. 每次推送到 main 分支会自动部署
