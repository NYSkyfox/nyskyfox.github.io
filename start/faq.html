❓ 常见问题 ​

基础问题 ​

Q：脚本运行后闪退怎么办？ ​

可能原因与解决方案：

  1. 杀毒软件拦截 — 某些杀软会拦截脚本的进程/服务操作，请添加白名单或暂时关闭杀软
  2. 权限不足 — 有些系统策略禁止运行 .bat 文件，请右键选择「以管理员身份运行」
  3. 路径含空格 — 确保文件路径不含特殊字符

Q：为什么提示"不是内部或外部命令"？ ​

脚本依赖 Windows 自带的 sc、taskkill、tasklist、powershell 等命令。如果你的系统精简版移除了这些组件，可能无法正常运行。完整版 Windows 7/8/10/11 均自带。

Q：脚本被杀毒软件报毒怎么办？ ​

脚本的操作（终止进程、删除服务、删除驱动文件）与病毒行为类似，导致杀软误报。解决方案：

  • 将脚本添加至杀软白名单/信任区
  • 临时关闭实时监控（不推荐长期关闭）
  • 可以使用在线查毒平台验证脚本安全性

Q：需要联网才能使用吗？ ​

不需要。 脚本是纯本地批处理文件，完全离线运行，不需要网络连接。

功能相关问题 ​

Q：一键解锁后，过一会儿又被控制了怎么办？ ​

这是因为噢易学生端有自动保护机制，某些进程被终止后会自动重启。

解决方案：

  1. 再次运行一键解锁
  2. 然后进入 进程管理 → 持续监控模式（选项 11）
  3. 持续监控模式会每 2 秒自动终止关键进程，防止反弹

Q：解锁后会影响正常上课吗？ ​

不会影响电脑的基本使用。解锁后你可以：

  • 正常上网浏览
  • 正常使用键盘鼠标
  • 正常使用U盘
  • 唯一变化：学生端管理功能被绕过，老师端可能显示该机器离线

Q：如何恢复USB限制？ ​

由于 easyusbflt 服务已被删除，如需恢复：

  1. 重新安装噢易学生端软件
  2. 或联系机房管理员恢复环境

Q：ProcessProtect.exe 杀不死怎么办？ ​

ProcessProtect.exe 是噢易的进程保护程序，存在自我保护机制。如果 taskkill 无法终止：

  • 尝试先停止 MMPC 服务（它可能负责保护该进程）
  • 使用挂起功能暂停而非终止

Q：一键解锁花了多长时间？ ​

通常 10~20 秒 内即可完成全部 5 个步骤。每个步骤之间有短暂的命令执行时间。

兼容性问题 ​

Q：脚本支持 Windows 11 吗？ ​

支持。已在 Windows 10 和 Windows 11 上测试通过。Windows 7/8 同样兼容。

Q：适用于所有噢易版本吗？ ​

脚本针对常见的噢易多媒体教学系统设计，大部分学校机房使用的版本均可兼容。如果发现某个功能无效，请检查学生端版本是否使用了不同的进程/服务名。

Q：可以在 64 位系统上运行吗？ ​

完全可以。脚本会自动检测安装路径，优先检测 Program Files (x86)，兼容 x86 和 x64 系统。

技术问题 ​

Q：脚本如何实现管理员提权？ ​

通过 PowerShell 调用 Start-Process 并指定 -Verb RunAs 参数，以管理员身份重新启动自身：

powershell
Start-Process '%~f0' -Verb RunAs

这是一种安全常见的提权方式，Windows UAC 会提示用户确认。

Q：如何自己修改脚本？ ​

使用记事本或任意文本编辑器打开 .bat 文件即可查看和修改代码。脚本结构清晰，包含主菜单、子程序、功能模块等注释分区。

Q：可以添加新的解锁项吗？ ​

当然可以。脚本是开源的 Bat 脚本，你可以：

  1. 在 :main_menu 中添加新菜单项
  2. 新增对应的功能标签（如 :unlock_new_feature）
  3. 按现有子程序格式编写功能代码

其他问题 ​

Q：这个工具的开发者是谁？ ​

作者是 NyxFox。该工具最初基于 Python 脚本实现，后移植为纯 Bat 脚本，使其无需依赖任何运行环境即可运行。

Q：工具会更新吗？ ​

作者可能会根据噢易新版本的变化进行更新。请关注最新版本发布。

Q：使用这个工具会被老师发现吗？ ​

在一定程度上可能被发现。 当停止 MMPC 服务或终止 Student.exe 后，老师端的控制台可能会显示该机器离线或异常。使用时请注意周围环境。

Q：有 Mac/Linux 版本吗？ ​

没有。噢易学生端仅存在于 Windows 环境中，本工具也只支持 Windows 平台。
