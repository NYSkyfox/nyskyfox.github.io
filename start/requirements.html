运行要求 ​

操作系统 ​

项目要求
操作系统Windows 7 / 8 / 8.1 / 10 / 11
系统架构x86 或 x64 均可
权限要求管理员权限（脚本自动提权）

适用环境 ​

本工具专门针对 噢易（Os-Easy）多媒体教室学生端 设计，适用于：

  • 学校机房 / 多媒体教室安装了噢易学生端软件的电脑
  • 学生端版本涵盖常见的噢易多媒体教学系统版本

不需要 ​

  • ❌ 不需要安装任何编程语言运行时（如 Python、Java 等）
  • ❌ 不需要安装第三方工具
  • ❌ 不需要网络连接（脚本在断网环境下同样可用）

已知限制 ​

  • 杀软误报：由于脚本涉及进程终止、服务删除、驱动文件删除等操作，部分杀毒软件可能会误报。如有必要请添加白名单。
  • 仅限 Windows：此为 Windows Bat 脚本，无法在 Linux / macOS 下运行。
  • 学生端版本差异：不同学校部署的噢易学生端版本可能略有差异，如遇到某些功能无效，请检查学生端是否更新了进程名称或服务名。
