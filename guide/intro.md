# 简介

**OsEasy-ToolKit** 是一个噢易多媒体教学系统学生端工具箱，提供解锁、进程管理、广播控制等核心功能

<div style='display: none'> 
> 之所以使用 Python Tkinter 重构，是因为学校机房的网速慢到极点，原版即使 38MB 的工具箱也要下载很久。于是基于 [ZiHaoSaMa66](https://github.com/ZiHaoSaMa66) 的 [OsEasy-ToolBox](https://github.com/ZiHaoSaMa66/OsEasy-ToolBox) 重构。
</div>

## 📦 核心功能

| 模块 | 功能 |
|------|------|
| **进程管理** | 挂起/恢复学生端进程、切换 MMPC 根服务、粘滞键后门注册 |
| **解锁管理** | 删除键盘锁/控屏/黑屏安静、解锁网络/USB 限制、文件备份恢复 |
| **广播管理** | 替换 ScreenRender 拦截命令、窗口化/全屏广播、快捷键支持 |
| **广播命令** | 手动输入/编辑命令、从教师机 IP 生成、从日志提取、导入/导出 |
| **DLL 工具** | USB 管控启停、网络管控开关 |

## ⚠️ 注意事项
