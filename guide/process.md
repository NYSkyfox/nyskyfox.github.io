# 🔧 进程管理

> 管理学生端进程运行状态，提供重启、挂起、劫持与远程关机/重启防护等功能。

## 进程操作
| 操作 | 说明 |
|------|------|
| **重启学生端** | 结束当前学生端进程并重新启动（由 MMPC 服务统一调度） |
| **重新获取学生端路径** | 自动重新检测学生端安装路径与运行版本 |

## 功能开关
| 开关 | 说明 |
|------|------|
| **劫持粘滞键 (sethc.exe)** | 用 `cmd.exe` 替换 `sethc.exe`，在登录界面连按 5 次 Shift 可打开管理员命令行（提权后门） |
| **循环杀死学生端** | 启动守护进程持续终止学生端进程，防止被 MMPC 服务自动拉起 |
| **挂起学生端** | 挂起（暂停）学生端进程，教师端监控画面停止更新且不显示掉线 |

::: tip 挂起 vs 结束
挂起进程：教师端画面停止更新但**不显示掉线**，不易被察觉；
直接结束进程：可脱离控制但教师端会显示**掉线**，容易被发现。
:::

## 防护
| 开关 | 说明 |
|------|------|
| **拦截教师端远程关机** | 通过 IFEO 劫持 `shutdown.exe`，阻止教师端远程关机指令 |
| **拦截教师端远程重启** | 移除学生端进程的关机权限（⚠️ 标注"暂不可用"，请勿尝试） |

::: warning 注意
开启「拦截远程关机」时若检测到其他程序已劫持该键值，会弹出冲突确认框，由你决定是否继续。
:::

## 快捷操作
| 操作 | 说明 |
|------|------|
| **打开噢易自带工具** | 启动学生端自带的管理工具 `AssistHelper.exe` |
| **打开OsEasy安装目录** | 在资源管理器中打开学生端安装目录 |
| **打开ToolKit数据文件夹** | 打开工具箱数据目录（备份/日志/配置/截图所在） |
