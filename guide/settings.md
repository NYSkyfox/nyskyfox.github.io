# ⚙️ 设置

> 自定义工具箱的外观、快捷键与窗口行为。

## 外观设置
| 功能 | 说明 |
|------|------|
| **切换背景图片** | 选择一张图片作为工具箱窗口背景 |
| **更换显示字体** | 选择自定义字体文件（需重启生效） |
| **加载外部一言文件** | 从外部文本文件加载自定义一言列表（每行一条） |

## 背景不透明度
调节背景图片的不透明度（0 = 透明 ~ 1 = 不透明）。

## 快捷键
可配置的全局快捷键（使用 pynput 监听，工具箱最小化时仍生效）：

| 快捷键 | 默认功能 |
|--------|----------|
| 运行窗口屏幕广播 | 以窗口模式运行广播命令 |
| 杀屏幕广播进程 | 强制终止屏幕广播进程 |
| 运行全屏广播命令 | 以全屏模式运行广播命令 |
| 隐藏/显示工具箱 | 快速隐藏或显示工具箱窗口 |

> 广播页的快捷键开关与本页联动，可在此调整按键组合。

## 窗口
| 功能 | 说明 |
|------|------|
| **窗口置顶** | 让工具箱窗口始终显示在其他窗口之上 |
| **操作完成提醒 (Toast)** | 启用后部分操作完成时通过 Windows 桌面通知提醒 |

## 重置
**重置工具箱设置**：清除所有自定义设置并恢复默认配置。

::: tip 提示
开启「随机一言」后，每次切换页面时会在标签页顶部随机显示一句一言。
:::
