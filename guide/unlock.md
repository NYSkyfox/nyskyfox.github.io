# 🔓 解锁管理

> 所有解除学生端管控的操作集中于此页，提供一键脱离管控与单项解锁，使用原生 Windows API（winreg / SCM / 进程控制）实现。

## 一键操作
**一键脱离管控（解锁全部）**：依次执行
1. 网络管控解锁（`OeNetLimit` + `ProcFireWall`）
2. USB 管控解锁（`easyusbflt`）
3. 键盘鼠标锁解锁（`KbFilter`）
4. 屏幕广播 / 黑屏肃静移除
5. 目录保护移除（`FbdATS`）

## 单项解锁
| 功能 | 说明 |
|------|------|
| **仅解锁键盘鼠标驱动** | 停止 `KbFilter` / `ProcFireWall` 驱动、清理注册表过滤驱动项、删除驱动文件 |
| **仅停止网络管控服务** | 停止 `MMPC` / `OeNetLimit` / `ProcFireWall` 网络管控服务 |
| **仅关闭USB管控服务** | 停删 `easyusbflt` USB 过滤驱动、清理注册表过滤驱动项、删除驱动文件 |
| **仅移除黑屏肃静** | 结束 `BlackSlient.exe` 进程并删除黑屏肃静相关文件 |
| **仅移除屏幕广播** | 结束广播进程并删除控屏相关文件 |

## 确认弹窗
点击任何解锁操作都会弹出确认对话框，包含：
- 将要执行的操作清单
- **"操作完成后自动注销"** 开关（勾选后解锁完成会自动注销当前用户，部分驱动删除/注册表清理需要注销或重启才能完全生效）

::: warning 注意
- 所有解锁操作在**后台线程**执行，不会卡死界面，输出区实时显示进度。
- 解锁过程会**先备份**涉及的关键文件（调用文件管理页的备份逻辑），以便误操作后可恢复。
:::
