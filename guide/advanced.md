# 🚀 高级

> 远程功能与学生端安装/卸载测试工具。

## 远程功能（发送崩溃载荷）
向目标 IP 发送崩溃载荷，触发远端 Os-Easy 监控进程终止。

| 参数 | 说明 |
|------|------|
| **目标 IP/网段** | 支持单 IP 或 CIDR 网段（如 `192.168.1.0/24`） |
| **端口** | 目标端口号，默认噢易多媒体通信端口 |
| **载荷** | 发送的崩溃载荷内容，默认 `oshack\r\n` |

**操作流程**：
1. 输入目标 IP/网段（网段最多展开前 64 个主机）
2. 设置端口与载荷（可自定义）
3. 点击「发送崩溃指令」，后台线程执行，输出区显示结果

## 学生端安装测试
在指定目录下生成并运行学生端安装/卸载测试脚本（含 `MMPC.exe` / `DriverInstall.exe` 的套件目录）。

| 功能 | 说明 |
|------|------|
| **生成并运行安装测试脚本** | 注册 `MMPC` 服务、安装管控驱动、添加防火墙规则 |
| **生成并运行卸载测试脚本** | 停止/删除 `MMPC` 与管控驱动、删除防火墙规则 |

- 远程崩溃与安装/卸载测试属于**高风险操作**，仅用于学习和授权环境。
- 请遵守机房管理规定，勿用于绕过学校管控或非法操作。
