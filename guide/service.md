# ⚙️ 服务管理

> 查看并启停学生端相关的 Windows 服务与内核驱动，使用原生 SCM API 操作，不弹出命令行窗口。

## 服务列表

| 服务名 | 描述 |
|--------|------|
| `MMPC` | 噢易多媒体根服务（学生端中心服务，负责拉起被关闭的进程） |
| `OeNetLimit` | 网络管控驱动（WFP 过滤平台） |
| `easyusbflt` | USB 过滤驱动 |
| `KbFilter` | 键盘过滤驱动（IRP 拦截） |
| `ProcFireWall` | 进程防火墙 |
| `FbdATS` | 文件系统过滤驱动（目录保护） |

## 操作方式
- 每个服务行右侧显示当前状态：**运行中**（绿）/ **未运行**（红）/ **不存在**（灰）
- 点击对应按钮可在 **启动 / 停止** 之间切换
- **刷新状态**：重新查询全部服务状态

## 内核驱动强制卸载
普通服务可正常停止；但对于**不接受停止控制的内核驱动**（如 `easyusbflt`、`KbFilter`、`FbdATS`），工具会自动降级为**强制卸载**流程：

1. 停止失败后检测服务类型是否为内核驱动 / 文件系统驱动
2. 若是，则执行强制卸载：
   - `sc delete` 删除服务
   - 清理注册表中的**过滤驱动关联项**（LowerFilters / UpperFilters / 设备类过滤）
3. 输出区会显示完整过程

::: warning 注意
- 停止 `MMPC` 后，部分功能（如"重启学生端"）依赖其调度，操作前请确认需求。
- 强制卸载驱动会永久删除相关注册表项，重新启用需要重装学生端或恢复备份（见文件管理页）。
:::
