# 📺 广播管理

> 管理屏幕广播的拦截与运行，支持替换广播程序、窗口化/全屏运行广播命令、日志监控与远程命令管理。

## 使用说明（点击页面内「点我查看此页面的使用说明」可再次查看）
1. 使用前先解锁键盘锁 & 删除控屏锁定程序
2. 点击「替换拦截程序」再恢复控屏软件
3. 等待老师控制屏幕后即完成拦截远程命令
4. 完成替换后可重新删除控屏软件
5. 老师处于控制状态时，可主动运行命令**弹出窗口化共享屏幕**，自由的同时不影响听课
6. 老师来时用快捷键启动全屏参数控制，走后用快捷键清理进程

## 替换状态
- 检测 `ScreenRender.exe` 是否已被替换为自定义程序（`ScreenRender_Y.exe`）
- 点击状态栏可刷新检测

## 广播操作
| 操作 | 说明 |
|------|------|
| **替换拦截命令程序** | 用自定义程序（`ScreenRender_Helper.exe`，需与工具箱同目录）替换 `ScreenRender.exe`，拦截教师端广播命令（耗时约 6 秒） |
| **运行窗口化广播命令** | 以窗口模式运行拦截到的广播命令，可自由切换窗口 |
| **运行全屏广播命令（长按）** | 长按按钮以全屏模式运行广播命令，松开即止 |
| **杀屏幕广播进程** | 强制终止 `ScreenRender` 屏幕广播进程 |
| **恢复原有屏幕广播程序** | 将 `ScreenRender.exe` 恢复为原始程序，取消拦截 |

## 快捷键
| 开关 | 说明 |
|------|------|
| 运行窗口屏幕广播 | 快捷键以窗口模式运行广播命令 |
| 杀屏幕广播进程 | 快捷键强制终止屏幕广播进程 |
| 运行广播命令 | 快捷键以全屏模式运行广播命令 |

## 远程广播命令
| 功能 | 说明 |
|------|------|
| **教师机 IP 地址** | 输入教师机 IP，用于生成远程广播命令 |
| **由教师机 IP 生成远程命令** | 自动生成远程命令并保存到配置 |
| **完整远程广播命令** | 手动输入/编辑完整命令行参数 |
| **自动替换本地 IP 并更新命令** | 自动替换命令中的 IP 为本机 IP 并保存 |
| **手动更新完整远程广播命令** | 直接保存手动编辑的命令，不自动替换 IP |

## 日志操作
| 功能 | 说明 |
|------|------|
| **从日志文件获取远程命令** | 从 OsEasy 日志中提取教师端发送的远程命令 |
| **读取已拦截的广播命令** | 读取并显示已被拦截保存的广播命令参数 |

## 自动监控
**自动监控广播日志（全屏自动转窗口）**：持续监控广播日志，检测到全屏广播时自动切换为窗口模式，避免被强制全屏。
