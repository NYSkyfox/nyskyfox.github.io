# 📊 概览页

> 进入工具箱后的第一个页面，实时展示学生端与工具箱的整体运行状态，每 3 秒自动刷新（仅当概览页可见时生效）。

## 功能说明

### 工具箱状态
| 项目 | 说明 |
|------|------|
| 版本 | 当前工具箱版本号（如 v1.9.0） |
| 学生端路径 | OsEasy 学生端安装目录（默认 `C:\Program Files (x86)\Os-Easy\os-easy multicast teaching system\`） |
| 学生端进程 | 当前检测到的学生端主进程名（通常为 `Student.exe`） |
| 学生端版本 | 自动读取学生端版本文件并解析，失败时显示红色提示 |

### 学生端服务（左侧列表）
实时检测以下服务的运行状态（运行中 ● / 未运行 ○ / 不存在 ○）：

| 服务名 | 作用 |
|--------|------|
| `MMPC` | 噢易多媒体根服务（学生端中心服务） |
| `OeNetLimit` | 网络管控驱动 |
| `easyusbflt` | USB 过滤驱动 |
| `KbFilter` | 键盘过滤驱动 |
| `ProcFireWall` | 进程防火墙 |
| `FbdATS` | 文件系统过滤驱动（目录保护） |

### 学生端进程（右侧列表）
实时检测以下进程是否在运行：

| 进程 | 作用 |
|------|------|
| `Student.exe` | 学生端主进程（按检测到的实际名称显示） |
| `MultiClient.exe` | 通信客户端 |
| `BlackSlient.exe` | 黑屏肃静执行器 |
| `DeviceControl_x64.exe` | 设备管控 |
| `ScreenRender.exe` | 屏幕广播 |
| `LissHelper.exe` | 辅助程序 |

## 操作
- **刷新状态**：点击「刷新状态」按钮立即重新检测全部服务与进程状态。
- 页面停留时每 3 秒自动刷新；切换到其他标签页后自动暂停，节省资源。

::: tip 提示
绿色圆点 ● = 运行中，橙色圆点 ○ = 未运行，灰色 ○ = 服务/进程不存在。
:::
