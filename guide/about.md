# ℹ️ 关于

> 工具箱版本信息、GitHub 入口与权限状态展示。

## 内容
| 项目 | 说明 |
|------|------|
| 标题 | 当前版本号（如 `OsEasy-ToolKit v1.9.0`） |
| GitHub | 一键跳转到仓库页面 |
| 权限状态 | 当前是否以管理员身份运行 |
| 构建日期 | 打包时写入的构建时间 |

## 提权方式显示
关于页会显示当前使用的提权方式：

| 方式 | 说明 |
|------|------|
| **Fodhelper 注册表绕过**（静默） | 默认首选，静默提权无弹窗 |
| **Eventvwr 注册表绕过**（静默备选） | 备选方案 |
| **UAC 弹窗确认** | 前两种失败时的回退方案 |
| **应用清单 (manifest)** | 已以管理员身份运行 |

## 启动时的提权流程
程序启动时自动执行**三级降级提权**：
1. `fodhelper` 注册表绕过（静默，无弹窗）
2. `eventvwr` 备选绕过（静默）
3. 标准 UAC 弹窗
