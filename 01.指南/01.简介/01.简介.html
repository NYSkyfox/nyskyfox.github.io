简介 ​

✨ 项目简介 ​

OsEasy-ToolKit 是一个基于 Python Tkinter 重构的噢易多媒体教学系统学生端工具箱，提供解锁、进程管理、广播控制等核心功能。

之所以使用 Python Tkinter 重构，是因为学校机房的网速慢到极点，原版即使 38MB 的工具箱也要下载很久。于是基于 ZiHaoSaMa66 的 OsEasy-ToolBox 重构。

🚀 快速使用 ​

bash
# 安装依赖
pip install -r requirements.txt

# 运行
python main.py

# 打包发布
python build.py          # 正式版
python build.py --debug  # 调试版

📦 核心功能 ​

模块功能
进程管理挂起/恢复学生端进程、切换 MMPC 根服务、粘滞键后门注册
解锁管理删除键盘锁/控屏/黑屏安静、解锁网络/USB 限制、文件备份恢复
广播管理替换 ScreenRender 拦截命令、窗口化/全屏广播、快捷键支持
广播命令手动输入/编辑命令、从教师机 IP 生成、从日志提取、导入/导出
DLL 工具USB 管控启停、网络管控开关

⚠️ 注意事项 ​

  • 需要以 管理员权限 运行
  • 适用于 噢易 V10.8+ 学生端
  • 使用前请确保已 备份重要文件
  • 若在学校因使用工具箱被物理制裁，一切责任与作者无关

🌟 技术特点 ​

  • 解耦架构：配置、服务、页面完全分离，代码结构清晰，易于维护和扩展
  • 极致轻量：基于 tkinter + ttk GUI 框架，打包体积极小，网速慢也能快速下载使用
  • 功能全面：支持进程管理、解锁管理、广播管理、广播命令、DLL 工具等核心功能
  • 专注场景：专为噢易 V10.8+ 学生端设计，覆盖机房日常使用的各类管理需求
