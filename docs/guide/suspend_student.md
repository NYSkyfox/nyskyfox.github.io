# 教程篇-挂起/暂停学生端进程

> 前言：**挂起/暂停学生端进程** 可以让教师端对学生端的监控的画面停止更新，可方便同学们 **“自主学习”**，防止牢逝通过教师端的监控画面看到。
与直接 **结束学生端进程** 不同，仅 **挂起/暂停学生端进程** 只会让教师端对学生端的监控的画面停止更新，而不会显示为掉线。相反，直接结束 **结束学生端进程** 会在教师端显示为该学生端掉线，容易被牢逝察觉，导致被制裁。

## 适用场景

- 想要自主学习，但是担心被牢逝发现
- 想了解相关原理

## 操作步骤

### 一：打开 `任务管理器`

::: info 一：打开 `任务管理器`

**操作示例：**

1. 在任务栏空白位置单击鼠标右键，点击 **打开任务管理器(K)**
2. 在弹出的窗口中点击左下角的 **详细信息**

:::

### 二：打开 `资源监视器`

::: info 二：打开 `资源监视器`

**操作示例：**

1. 任务管理器默认选项开为 **进程**，请在顶栏切换到性能选项卡
2. 点击底部的 **打开资源监视器**
3. 点击 `名称` 二字，切换到名称排序（*由于列表的默认排序方式为状态，但部分程序的状态在改变，导致列表变化很快，不易精准找到 `Student.exe`，因此建议点击名称以切换到名称排序*）

:::

### 三：暂停 `Student.exe` 进程

::: info 三：暂停 `Student.exe` 进程
1. 往下拉找到名为 `Student.exe` 的进程
2. 右键单击该进程，在弹出的菜单里选择 `暂停进程(S)`
