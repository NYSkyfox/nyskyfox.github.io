## 关于这个网站

这是一个基于 VitePress 构建的个人网站，主题色为 **#16c07c**，默认使用暗色模式。

## 技术栈

- **VitePress** - 现代化的静态站点生成器
- **Vue 3** - 渐进式 JavaScript 框架
- **GitHub Pages** - 静态网站托管服务

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev

# 构建生产版本
npm run docs:build
```
