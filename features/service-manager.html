🛠️ 服务管理 ​

主菜单选项：6

服务管理允许你单独控制噢易学生端的各个后台服务，精细化管理电脑的运行状态。

可管理的服务 ​

编号服务名说明
1MMPC学生端根服务 — 学生端的核心服务，控制所有子模块
2OeNetlimit网络限制服务 — 负责网络访问过滤和封锁
3easyusbfltUSB管控服务 — 负责USB存储设备的禁用控制

支持的操作 ​

对每个服务，你可以执行以下操作：

操作说明
停止临时停止服务运行，重启电脑后可能自动恢复
启动重新启动已停止的服务
重启先停止再启动，用于让服务重新加载配置
删除从系统中彻底移除该服务，重启后也不会自动恢复

批量操作 ​

选项 4 停止所有服务 — 一键停止以上所有三个服务。

使用场景 ​

  • 🎯 网络解锁后又恢复 → 检查 OeNetlimit 是否又启动了，直接删除它
  • 🎯 想彻底摆脱学生端 → 删除 MMPC 服务（谨慎操作）
  • 🎯 USB解锁后又失效 → 检查 easyusbflt 服务状态
  • 🎯 测试不同组合 → 分别停止某个服务观察效果

执行方式 ​

选择服务后，会有 5 秒倒计时，你可以按任意键立即开始执行。

注意事项 ​

谨慎操作

  • 删除服务是永久性操作，一旦删除，只有重新安装噢易软件才能恢复。
  • 如果只是想临时绕过限制，使用「停止」即可。
  • 删除 MMPC 服务可能导致学生端无法正常运行，老师端可能会显示该机器离线。
