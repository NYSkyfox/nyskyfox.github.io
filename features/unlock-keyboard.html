⌨️ 解锁键盘鼠标锁 ​

主菜单选项：4

当键盘和鼠标被锁定，无法进行任何输入操作时，使用此功能恢复输入设备的正常使用。

执行流程 ​

步骤 1：终止键鼠控制进程并删除驱动文件 ​

  • 终止 BlackSlient.exe — 黑屏/键鼠锁定进程
  • 终止 MultiClient.exe — 学生端主进程
  • 自动检测噢易安装路径
  • 删除键盘锁驱动文件：
    • LockKeyboard.dll — 键盘锁定动态库
    • LoadDriver.exe — 驱动加载程序
    • BlackSlient.exe — 黑屏锁定程序
    • LISSNetInfoSniffer.exe（位于 x86 子目录）

步骤 2：删除网络限制相关文件 ​

在噢易安装目录中自动清理 OeNetLimit 文件：

  • OeNetLimitSetup.exe — 网络限制安装程序
  • OeNetLimit.sys — 网络限制驱动文件
  • OeNetLimit.inf — 网络限制配置信息

手动执行命令 ​

在 CMD（管理员身份）中依次执行以下命令：

命令 1：终止黑屏/键鼠锁定进程 ​

batch
taskkill /f /im BlackSlient.exe

强制终止黑屏和键鼠锁定进程，恢复屏幕显示和输入设备。

命令 2：终止学生端主进程 ​

batch
taskkill /f /im MultiClient.exe

强制终止学生端主进程 MultiClient.exe，停止其管控逻辑。

命令 3：删除键盘锁驱动文件 ​

batch
del /F /Q "C:\Program Files (x86)\Os-Easy\os-easy multicast teaching system\LockKeyboard.dll"

删除键盘锁定动态库文件，彻底解除键盘锁定。如果噢易安装在 C:\Program Files 目录，请相应调整路径。

命令 4：删除驱动加载程序 ​

batch
del /F /Q "C:\Program Files (x86)\Os-Easy\os-easy multicast teaching system\LoadDriver.exe"

删除驱动加载程序，防止键盘锁驱动被重新加载。

使用场景 ​

  • ✅ 键盘被锁定，无法打字或按任何键
  • ✅ 鼠标被锁定，光标无法移动或点击无效
  • ✅ 全键盘 / 全鼠标被老师远程禁用
  • ✅ 同时存在黑屏状态（此功能同时处理 BlackSlient.exe）

效果说明 ​

执行后：

  • 键盘恢复正常，可以输入文字
  • 鼠标恢复正常，可以自由移动和点击
  • 黑屏状态解除（如果存在）

常见问题 ​

Q：终止后又锁了怎么办？ ​

学生端可能自动重启了相关进程。可以再次执行终止命令，或使用 持续监控模式。

Q：删除驱动文件提示权限不足？ ​

确保已以管理员身份运行 CMD。如果仍然提示，可以先尝试在安全模式下删除。

注意事项 ​

注意

部分机房环境在重启学生端后键盘锁驱动可能被重新加载。如果再次遇到键盘鼠标锁，重新运行此功能即可。
